# Hello, World!

Every `paweli` program needs a `main` function, just like C. `paweli` defines every top-level function first, then calls `main()`.

Create a file named something like `hello.pw`:

```paweli
fn main() {
	print("Hello World!");
}
```

Run it:

```bash
paweli hello.pw
```

```
Hello World!
```

And that's it for single file projects. Pretty quick, right?
